# exercises-in-style

インタラクティブなデータ可視化の連作です。二つの翼があります。

- **データの文体練習**（`style/`）：データを一つに固定し、語り方を変えて99通りに語り直す。
- **記譜法を借りる**（`notation/`）：既存の記譜法を借り、その構造に合うデータを選んで書く。

制作：Claude（Anthropic）／企画・監修：矢崎裕一

計画書：https://claude.ai/artifact/7jdyWsXZsM17GbiuxvC69a
台帳：[LEDGER.md](LEDGER.md)

## 約束ごと

禁じ手カードと衝突するときは禁じ手が優先する。出典だけは必ず残す。

1. **一作一身振り**：読み取りに使う動作は1つに絞り、その動作にデータを1変数割り当てる。
2. **数字は最後**：まず身体で分かり、数値は答え合わせとして出す。
3. **核を外さない**：文体練習は毎回、20行動への1440分の配分（`data/day-2021.json`）を含む。層（男女、年齢階級、曜日、時間帯、時系列、他国）は1作につき1つまで開けられる。
4. **文法を曲げない**：記譜法の規則は変えず、読める人がそのまま読めるようにする。
5. **出典と着想元を書く**：統計名・調査年・URLを各作品に置く。先例や着想元があれば名前を挙げる。
6. **一作で完結させる**：各作品は `index.html` 1ファイルで単独に動く。CSS・JavaScript・データをファイル内に持ち、外部への通信をしない。
7. **不採用も残す**：うまくいかなかった組み合わせは、理由を1行添えて台帳に残す。

## 文体練習のカード

1作ごとに、文体・禁じ手・身振りを1枚ずつ引く。成り立たないときは1枚だけ引き直せる。引いたカードと引き直した理由は台帳に書く。記譜法の翼では文体カードを引かない。

- **文体**
  - 視点：俯瞰／当事者の目線／一人を追う／夜から始める／終わりから遡る
  - 語り口：公文書／実況中継／天気予報／取扱説明書／絵本
  - 形式：俳句（17の要素だけ）／年表／レシピ／地図／すごろく
  - 感覚：音だけ／振動だけ／明るさだけ／動きだけ／大きさだけ
  - 修辞：誇張／控えめ／比喩／反復／倒置
  - 尺度：1日を1分に／1日を1年に／1人に／1億人に／一生に
  - 数理：確率として／集合として／差分だけ／順位だけ／割合だけ
- **禁じ手**：色なし／軸なし／数字なし／文字なし／直線なし／止まらない／画面なし（音だけ）／要素は3つまで／押せない（待つだけ）／1画面に収めない
- **身振り**：押す／長押し／待つ／なぞる／払う／引っぱる／傾ける／叩く／回す／つまむ／置く／声を出す

## 完成の定義

- スマートフォンとPCの両方で動く
- 説明を読まなくても、30秒で身振りに気づける
- 身振りが読み取りになっている（飾りになっていない）
- 数値を確かめられる
- 出典とクレジットがある
- 台帳に1行足してある

## 作品の体裁

- 置き場所：`style/NNN-slug/index.html`、`notation/NNN-slug/index.html`
- 言語は日本語（`<html lang="ja">`）。`<meta name="viewport" content="width=device-width, initial-scale=1">` を入れる。
- 紙のような静かな画面を基調にする。地 `#f4f1ea`、墨 `#1d1d1b`、薄墨 `#6b6860`、朱 `#c8452f`（強調は1か所だけ）。暗い画面の作品は地 `#111110`、文字 `#e9e6df`。
- 題と本文は明朝（`"Hiragino Mincho ProN","Yu Mincho","Noto Serif JP",serif`）、数値と操作部はゴシック（`"Hiragino Sans","Yu Gothic","Noto Sans JP",sans-serif`）。
- ページ上部に連作名・番号・題。下部に「答え合わせ」（数値）、出典、クレジット、トップ（`../../`）への戻り。
- ポインタ操作は Pointer Events で書き、マウス・タッチの両方で同じ身振りが使える。キーボードでも同じ読み取りができる代替を用意する。
- `prefers-reduced-motion` を尊重する。

## データ

- `data/day-2021.json`：文体練習の核。「令和3年社会生活基本調査結果」（総務省統計局）。
- `data/census.json`：国勢調査による総人口（5年ごと）。
